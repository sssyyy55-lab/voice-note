録音ノート — はじめての設定

話して、止めるだけ。要約されたGoogleドキュメントができあがります。
設定はこの最初の1回だけです。所要時間はおよそ10分。
費用はかかりません(無料枠のみで動きます)。クレジットカードの登録も不要です。
作成されたドキュメントはあなた自身のGoogleドライブに保存されます。他の人からは見えません。
1

Gemini APIキーを取得する

文章を要約するために使います。Googleアカウントがあれば無料で取得できます。

  1. aistudio.google.com/apikey を開く
  2. Googleアカウントでログインする
  3. 「APIキーを作成」をクリック
  4. プロジェクトを選ぶ画面が出たら、そのまま作成してよい
  5. AIza で始まる文字列が表示されるのでコピーして控えておく
APIキーは他人に見せないでください。 SNSへの投稿や画面共有にご注意を。万一漏れた場合は、同じページでキーを削除して作り直せば無効化できます。
2

Googleドキュメントを作る仕組みを用意する

Google Apps Script という無料の仕組みを使います。パソコンでの作業をおすすめします(スマホだと操作しづらいため)。

  1. script.google.com を開く
  2. 左上の「新しいプロジェクト」をクリック
  3. エディタに書かれている function myFunction() {} をすべて削除する(Ctrl+A → Delete)
  4. 下のコードをコピーして貼り付ける
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var title      = data.title      || '録音ノート';
    var summary    = data.summary    || '(なし)';
    var transcript = data.transcript || '(なし)';
    var folderName = data.folder     || '';

    var doc  = DocumentApp.create(title);
    var body = doc.getBody();
    body.clear();

    body.appendParagraph('要約').setHeading(DocumentApp.ParagraphHeading.HEADING2);

    summary.split('\n').forEach(function (line) {
      var t = line.trim();
      if (t === '') return;
      if (t.indexOf('## ') === 0) {
        body.appendParagraph(t.substring(3)).setHeading(DocumentApp.ParagraphHeading.HEADING3);
      } else if (t.indexOf('# ') === 0) {
        body.appendParagraph(t.substring(2)).setHeading(DocumentApp.ParagraphHeading.HEADING3);
      } else if (t.indexOf('- ') === 0 || t.indexOf('* ') === 0) {
        body.appendListItem(cleanMd(t.substring(2))).setGlyphType(DocumentApp.GlyphType.BULLET);
      } else {
        body.appendParagraph(cleanMd(t));
      }
    });

    body.appendParagraph('');
    body.appendParagraph('文字起こし全文').setHeading(DocumentApp.ParagraphHeading.HEADING2);
    body.appendParagraph(transcript);

    doc.saveAndClose();

    if (folderName !== '') {
      var folders = DriveApp.getFoldersByName(folderName);
      var folder  = folders.hasNext() ? folders.next() : DriveApp.createFolder(folderName);
      DriveApp.getFileById(doc.getId()).moveTo(folder);
    }

    return json({ ok: true, url: doc.getUrl(), id: doc.getId() });
  } catch (err) {
    return json({ ok: false, error: String(err) });
  }
}

function cleanMd(s) {
  return s.replace(/\*\*/g, '').replace(/`/g, '');
}

function json(obj) {
  return ContentService.createTextOutput(JSON.stringify(obj))
    .setMimeType(ContentService.MimeType.JSON);
}

function doGet() {
  return ContentService.createTextOutput('録音ノート出力スクリプトは動作しています。');
}
貼り付けたら1行目を確認してください。 function doPost(e) { で始まっていない場合、この説明文まで一緒にコピーされています。全部消して貼り直してください。
3

スクリプトを公開してURLを取得する

  1. 左上のプロジェクト名(「無題のプロジェクト」)をクリックし、録音ノート出力 などに変更
  2. フロッピーディスクのアイコンで保存
  3. 右上の「デプロイ」→「新しいデプロイ」
  4. 左の歯車アイコン(⚙)→「ウェブアプリ」を選択
  5. 次のユーザーとして実行:自分
  6. アクセスできるユーザー:全員
  7. 「デプロイ」をクリック
ここで「このアプリはGoogleで確認されていません」という警告が出ます。
これは自分で書いたスクリプトを自分で承認する場合に必ず出るものです。開発者欄にご自身のメールアドレスが表示されていることを確認したうえで、
「詳細」→「(プロジェクト名)に移動(安全ではないページ)」→ 権限をすべてチェックして「許可」と進んでください。

完了画面に表示される「ウェブアプリのURL」(/exec で終わるもの)をコピーして控えておきます。

動作確認: そのURLをブラウザのアドレスバーに貼って開き、「録音ノート出力スクリプトは動作しています。」と表示されれば成功です。
URLの取り違えにご注意ください。 上の動作確認をすると、アドレスバーが script.googleusercontent.com/... に変わります。これは転送先のURLで、アプリには使えません。
アプリに貼るのは、デプロイ完了画面に表示された script.google.com/macros/s/.../exec の方です。控えたものを使ってください。
4

アプリに登録する

  1. 下のボタンからアプリを開く
  2. 「⚙ 初期設定」をタップして開く
  3. Gemini APIキー に手順1のキーを貼り付け
  4. Google Apps Script のURL に手順3のURLを貼り付け
  5. 保存先フォルダ名(任意):録音ノート などお好みで
  6. 「接続をテスト」をタップして、両方に ○ がつくか確認する
  7. 「この端末に保存」をタップ
先にテストしてください。 設定が間違っていると、録音し終えてから気づくことになります。テストは数秒で終わり、どこが間違っているかを具体的に教えてくれます。
設定はお使いの端末内にのみ保存されます。作成者を含め、誰かに送信されることはありません。
スマホとパソコンの両方で使う場合は、それぞれで一度ずつ設定してください。

よくある質問

本当に無料ですか?
はい。要約に使うGemini APIには無料枠があり、個人が日常的に使う範囲であれば超えることはまずありません。Apps ScriptとGoogleドキュメントも無料です。クレジットカードの登録も不要です。
録音した内容はどこかに送られますか?
文字起こしはお使いの端末のブラウザ機能で行われます。要約のためにテキストがGoogleのGemini APIへ送られ、完成したドキュメントはあなた自身のGoogleドライブに保存されます。作成者のもとには何も届きません。

機密性の高い内容を扱う場合は、各サービスの利用規約をご確認のうえ、ご自身の判断でお使いください。
「429」というエラーが出ます
利用の上限に達したという意味です。1分ほど待ってから再実行すると通ることがあります。繰り返し出る場合は、初期設定の「使うモデル」で別のモデルを選んでみてください。Google AI Studio の「レート制限」ページで、無料枠が残っているモデル名を確認できます。
ドキュメントが作られません
デプロイ設定を確認してください。「アクセスできるユーザー」が全員になっていないと、アプリからスクリプトを呼び出せません。
Apps Scriptで「デプロイ」→「デプロイを管理」→ 鉛筆アイコンから確認・変更できます。
文字起こしがうまくいきません
自動文字起こしはブラウザの音声認識機能を使っているため、環境によって精度が変わります。うまくいかない場合は「キーボードの音声入力」モードに切り替え、入力欄でスマホ標準の音声入力(キーボードのマイクボタン)をお使いください。そちらのほうが安定します。

どちらの場合も、文字起こし欄は手で修正できます。要約前に直しておくと仕上がりが良くなります。
ホーム画面にアプリとして置きたい
iPhone/iPadのSafariでアプリを開き、下部の共有ボタン(□に↑)→「ホーム画面に追加」を選んでください。全画面のアプリとして起動します。
Androidの場合はChromeのメニューから「ホーム画面に追加」を選びます。
うまくいかないことを伝えたい
アプリ画面の一番下に表示されているバージョン(例:録音ノート v1.0)と、画面に出たエラーの文言を添えてお知らせください。どの版で起きているかが分かると原因を絞り込めます。

なお、アプリを更新しても古い画面が表示され続けることがあります。その場合はURLの末尾に ?v=2 のような文字を足して開き直すと、新しい版が読み込まれます。
